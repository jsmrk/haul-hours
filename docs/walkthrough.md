# Four-minute assessment walkthrough

This is a recording script, not a recorded Loom. Record 3–5 minutes after hosted live-provider checks pass, then add the accessible Loom URL to README.

| Time | Show and explain |
| --- | --- |
| 0:00–0:30 | State the Django/React monorepo and single-driver 70/8 assumptions. Enter current, pickup, drop-off and cycle used; choose full suggestions. Show optional departure/timezone. |
| 0:30–1:20 | Plan a short live route. Distinguish pickup arrival, drop-off arrival and completion after one-hour unloading. Select itinerary activity and show the corresponding map marker/road instructions. |
| 1:20–2:05 | Open a prepared multi-day live trip. Show actual fuel detours, 30-minute fuel activity, daily rests and a 34-hour restart for exhausted cycle. Explain bounded search and explicit provider/stop failures. |
| 2:05–2:50 | Open daily logs, change dates, select a duty trace. Show OFF/SB/D/ON totals, miles, locations, assumed outside-trip time and blank signature. Download one day/all-day PDF; show matching graph/totals. |
| 2:50–3:30 | Show Django duty transitions, independent audit, stop candidate/exit validation and timezone/DST clipping. One backend event timeline drives every output. |
| 3:30–4:00 | Show strict TypeScript, generated schemas, customized shadcn/Kraken tokens, mobile layout and passing test/CI commands. End with GitHub and hosted link. |

Use a fresh browser with live mode. Keep secrets and provider dashboards off screen. If demonstrating fixtures before publishing, clearly state that geometry and timings are illustrative and leave the Test data banner visible. Fixture success does not verify live road availability.
